# 🍳 Instituto do Sabor

Plataforma educacional desenvolvida para divulgação de cursos, eventos, conteúdos gastronômicos e gestão de informações institucionais do Instituto do Sabor.

O projeto foi construído com foco em experiência do usuário, responsividade, performance e facilidade de gerenciamento de conteúdo, oferecendo uma presença digital moderna para alunos, professores e visitantes.

---

## 📜 Notas

* Status: Em Produção
* Versão: 1.1.0
* Plataforma Web Responsiva
* Compatível com Desktop, Tablet e Smartphones
* Otimizada para SEO e dispositivos móveis

---

## 🎯 Objetivo

Disponibilizar uma plataforma digital moderna para divulgação de cursos, eventos, conteúdos gastronômicos e informações institucionais, fortalecendo a presença online do Instituto do Sabor e facilitando a comunicação com alunos e visitantes.

## ⚙️ Instalação

### Clonar o projeto

```bash
git clone https://github.com/seu-usuario/gestedu-frontend.git
```

### Entrar na pasta

```bash
cd gestedu-frontend
```

### Instalar dependências

```bash
yarn install
```

---

## ▶️ Executando Localmente

```bash
yarn dev
```

A aplicação estará disponível em:

```text
http://localhost:3000
```

---

## 🏗️ Build de Produção

```bash
yarn build
```

```bash
yarn start
```

A aplicação será executada na porta:

```text
4700
```
